# Healthcare-Claims-and-Root-Cause-Analysis
End-to-end root cause analysis of 2,500 healthcare claims identifying drivers of pre-submission claim errors, with automated validation checks in Python &amp; SQL and interactive Power BI dashboards. Found 68% of errors traced to ICD-10/CPT/NDC coding conflicts and documentation gaps; reduced validation time by 40%.
## Key Findings
68% of claim errors traced to coding conflicts across ICD-10, CPT, and NDC codes, along with documentation gaps
40% reduction in validation time by automating recurring claim validation checks
Identified front-end process improvements (registration accuracy, authorization verification) to prevent errors before claim submission
## Tools & Technologies
SQL – data extraction, joins, and validation queries
Python – automated claim validation checks
Power BI – interactive dashboards visualizing denial trends and root-cause drivers
## Approach
Data Collection & Cleaning – Extracted and validated 2,500 claim records with associated coding data
Root Cause Analysis – Quantified the contribution of ICD-10/CPT/NDC coding conflicts and documentation gaps to claim errors
Automation – Replaced manual review with reusable Python/SQL validation scripts, cutting validation time by 40%
Visualization – Built interactive Power BI dashboards to help stakeholders prioritize corrective actions
Recommendations – Documented front-end process improvements and a reproducible methodology for future claim audits
## Results
| Metric | Impact |
|--------|--------|
| Errors traced to top root causes | 68% |
| Validation time reduction | 40% |
| Claims analyzed | 2,500 |
## Reproducibility
The analysis methodology is documented for reuse in future claim audits and quality reviews. Process improvements recommended include registration accuracy checks and authorization verification before claim submission.
